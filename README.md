# Projekto Valdymo Programa

Paprasta ir intuityvi projekto valdymo priemonė, skirta užduočių organizavimui, stebėjimui ir bendradarbiavimui.

## Funkcijos

### Pradinis Ekranas
- **Prisijungimas/Registracija**: Saugi prieiga prie paskyros.
- **Projektų Sąrašas**: Peržiūrėkite jau sukurtus projektus.
- **Kurti Naują Projektą**: Greitai pradėkite naujus projektus.
- **Keisti ir trinti projektus**: Pakeisti projektų informaciją ir trinti jau užbaigtus projektus.
### Projekto ekranas
- **Projekto informacija**: Didesnis žvilgsnis į projekto detales.
- **Projekto užduočių sąrašas**: Peržiūrėti pridėtas užduotis.
- **Pridėti užduotį prie projekto**: Galimybė sukurti užduoti projektui.
- **Užduočių filtravimas**: Filtravimas pagal pavadinimą, užbaigimo datą, prioritetą, būseną.
- **Užduočių statuso pakeitimas**: Galima pakeisti projektus į neužbaigtas, užbaigtas būseną.
- **Užduočių trinimas**: Trinti užduotis su patvirtimu.
- **Užduočių keitimas**: Galima keisti užduočių informaciją.
## Veikimas

failą src folderį ir jame įrašyti jūsų firebase config informaciją, kurią gaunate iš firebase.

- **Buvo naudojamos šios react funkcijos**: Router, useState/useEffect, Context, reducer.
